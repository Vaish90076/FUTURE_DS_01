# 📊 Business Sales Performance Analytics

## 🎯 Objective
Analyze sales data to identify:
- Revenue trends
- Top-selling products
- Category performance
- Regional performance

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## 📁 Dataset
Superstore Dataset (Kaggle)

## 📊 Key Insights
- Highest revenue from Technology category
- Sales peak during November & December
- West region shows strong performance
- Few products contribute major revenue

## 📌 Files Included
- data/ → dataset
- notebook/ → analysis notebook
- output/ → charts (optional)

## 🚀 Conclusion
This project helps businesses understand sales performance and make data-driven decisions.
